1. Network Reconnaissance & Port Scanning (Nmap)

Essential Nmap flags for fast, stealthy, and comprehensive port discovery:

# Fast SYN Stealth Scan (Top 1000 Ports)
nmap -sS -T4 -v <TARGET_IP>

# Full Service Version Detection + Default NSE Scripts + OS
nmap -sC -sV -O -p- -T4 -oN nmap_full.txt <TARGET_IP>

# High-Speed All-Ports UDP Discovery
nmap -sU --top-ports 100 -T4 <TARGET_IP>

# Specific Vulnerability Script Scan
nmap --script vuln -p 80,443,445,3389 <TARGET_IP>

2. Linux Privilege Escalation Quick Checks

# Sudo permissions without password
sudo -l

# Find SUID binaries (Executes with root permission)
find / -perm -4000 -type f 2>/dev/null

# Inspect automated cronjobs
cat /etc/crontab /etc/cron.* 2>/dev/null
crontab -l

# Check readable shadow or writable passwd
ls -la /etc/passwd /etc/shadow
